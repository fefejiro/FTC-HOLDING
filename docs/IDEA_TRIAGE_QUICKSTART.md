# Idea Triage Quickstart

Last updated: 2026-03-19

## Use this whenever a new idea appears

Ask:
1. Does this help make money soon?
2. Does this strengthen a current product in a meaningful way?
3. Does this reduce repeated work or mental load?
4. Is this mostly just interesting?

## Then place it in one bucket

### Sell Now
Use if it can help close work or support outreach soon.

### Build Later
Use if it is good, but not important right now.

### Internal Leverage
Use if it will reduce repeated work or improve operator speed.

### Ignore / Park
Use if it is mostly distracting, premature, or low-leverage.

## Fast rule
If you cannot explain why it matters in the next 30 days, it is probably not active work.

## Relationship to dashboard
- only Sell Now and approved Internal Leverage items should compete for dashboard attention by default
- Build Later stays parked
- Ignore / Park gets recorded once and left alone
