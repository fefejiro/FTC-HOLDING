# Mission Control v1

Last updated: 2026-03-19
Owner: Mike / FTC HOLDING

## Purpose

Mission Control exists to make execution visible.

It is not a note system.
It is not a brainstorming board.
It is the visible operating surface for daily work, weekly rhythm, deadlines, follow-ups, and momentum.

The problem it solves is simple:
- out of sight becomes out of mind
- too many priorities become fog
- useful docs become buried
- execution gets lost between ideas, jobs, outreach, and platform work

Mission Control should keep the machine visible.

---

## Core Layers

### Layer 1: Mission Control Surface
This is the visible top layer.

It should show:
- today
- this week
- money move
- job move
- follow-ups
- deadlines
- blockers
- recurring routines

### Layer 2: Assistant / Operator Layer
This is where Manchi helps translate input into structure.

Examples:
- voice note becomes task
- idea becomes triage item
- job becomes resume tailoring target
- follow-up becomes reminder
- blocker becomes dashboard item

### Layer 3: Memory and Source of Truth
These are the documents that back up the visible surface.

Includes:
- Founder Dashboard
- Idea Triage Matrix
- Dual-Lane Tracker
- Weekly Execution Cadence
- Resume versions
- LinkedIn pack

Mission Control should reference them, not replace them.

## Mission Control Panels

## 1. Today
This is the daily command view.

### Show
- today’s money move
- today’s job move
- today’s follow-ups
- one product move if active
- one leverage move if active

### Rule
If it is not visible here, it is not a real priority today.

---

## 2. This Week
This is the weekly control layer.

### Show

- one job priority

- follow-ups due this week

### Rule
Do not carry too many live priorities.

This panel is the cadence engine.

## Calendar Structure

## Daily Blocks
### Block 1: Job Search and Applications
- 45 to 90 minutes
- search, shortlist, tailor, apply

### Block 2: High-Value Execution
- 45 to 90 minutes
- resume, profile, outreach, follow-up, company credibility work

### Block 3: Review and Reset
- 10 to 20 minutes
- dashboard update
- follow-up capture
- tomorrow setup

## Weekly Blocks
### Monday
- planning and priority selection

### Tuesday to Thursday
- execution and applications

### Friday
- review, follow-ups, shortlist refresh, and reset
