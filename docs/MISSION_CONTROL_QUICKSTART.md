# Mission Control Quickstart

Last updated: 2026-03-19

## What this is
Mission Control is the visible operating layer for work.

Use it when things feel foggy, split, or buried.

## What to check first
1. Today
2. This Week
3. Job Lane
4. Client Lane
5. Follow-Ups
6. Deadlines

## Daily use
### Morning
- identify today’s money move
- identify today’s job move
- identify follow-ups due

### Midday
- check whether movement is real
- if not, return to the clearest next action

### End of day
- update follow-ups
- clear stale tasks
- choose tomorrow’s first move

## Weekly use
### Monday
- choose the week’s priorities

### Friday
- review outcomes
- refresh shortlist
- decide what carries forward

## Current reality
Right now Mission Control runs through:
- Telegram as the visible control surface
- repo docs as the source of truth

That is enough for version 1.
