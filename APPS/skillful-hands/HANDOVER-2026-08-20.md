## Content and design maintenance

- Edit approved public wording, programme information, contact subjects and
  social links in `src/content/site.ts`.
- Keep photography in `public/` only when it is supplied or approved for web
  use. Optimise dimensions before committing it and use accurate alt text.
- Preserve the warm cream, deep brown and burnt-orange system. Red, olive and
  gold are supporting accents, not equal-weight brand colours.
- Use the full logo artwork. Do not recreate it in web fonts or use a cropped
  thumbnail that makes the mark unreadable.
- Keep programme detail images and copy as readable separate columns on
  desktop, stacked image-first on mobile. Do not restore the removed decorative
  ribbon or edge braid when it competes with content.

## Maintenance commands

From the repository root:

```bash
npm run build --workspace=@ftc/skillful-hands
npm run verify:production --workspace=@ftc/skillful-hands
```

Before a content release, review the app at 375px, 430px, 768px, 1024px and
1440px. Check navigation, all primary links, email actions, image crops,
wrapping, focus states and horizontal overflow. The reusable delivery process
is documented in [REUSABLE_STATIC_SITE_PLAYBOOK.md](./REUSABLE_STATIC_SITE_PLAYBOOK.md).
