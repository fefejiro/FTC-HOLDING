# Play Store Assets Checklist

## 📸 Screenshots Required (Task A3)

Play Store requires **2-8 screenshots** showing key features:

### Phone Screenshots (Required)
- **Size**: 1080x1920px or 1080x2340px (9:16 or 9:19.5 aspect ratio)
- **Format**: PNG or JPG (24-bit, no alpha)
- **Minimum**: 2 screenshots
- **Recommended**: 4-8 screenshots

### Suggested Screenshots to Capture:
1. **Messaging** - Show AI tone analysis in action
2. **Conch Mode** - Structured conversation interface
3. **Calendar** - Shared custody calendar with events
4. **Expenses** - Expense tracking and splitting
5. **Dashboard** - Main app interface
6. **Onboarding** - One of the vibrant carousel slides (optional)

### How to Capture:
1. Open PeacePad on an Android device or emulator
2. Navigate to each feature
3. Take screenshots using device screenshot tool
4. Ensure screenshots show realistic data (not empty states)
5. Remove any personal/test data before submission
