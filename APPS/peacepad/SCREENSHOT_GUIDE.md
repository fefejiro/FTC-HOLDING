# Play Store Screenshot Guide for PeacePad

## Overview
You need **8 screenshots** in **1080 x 1920 pixels** (9:16 portrait ratio) format. These will showcase PeacePad's key features in the Play Store listing.

## Screenshot Specifications
- **Format:** PNG (preferred) or JPG
- **Dimensions:** 1080 x 1920 pixels (portrait, 9:16 ratio)
- **File Size:** Max 8 MB per screenshot
- **Device:** Capture on mobile device or use mobile view (F12 > Toggle device toolbar in Chrome)
- **Quality:** High resolution, clear text, vibrant colors

## Tips for Great Screenshots

### 1. Use Sample Data
Make sure you have realistic sample data:
- Messages that show positive co-parenting communication
- Calendar events like "Soccer practice", "Doctor appointment", "School pickup"
- Tasks like "Buy school supplies", "Schedule dentist appointment"
- Expenses like "Soccer cleats - $45", "School lunch - $30"

### 2. Show Active Features
- Use Guest or test account to generate realistic data
- Show features in use (not empty states)
- Demonstrate value visually

### 3. Mobile View Capture
**Option A - Real Device:**
- Use your phone to navigate and screenshot directly

**Option B - Chrome DevTools:**
1. Press F12 to open DevTools
2. Click "Toggle device toolbar" (Ctrl+Shift+M)
3. Select device: "Pixel 5" or "iPhone 12 Pro"
4. Set dimensions: 1080 x 1920 (custom if needed)
5. Capture screenshot: DevTools > ⋮ (three dots) > "Capture screenshot"

### 4. Clean UI
- Hide any development tools or debug info
- Make sure dark/light mode is consistent across screenshots
- Use vibrant brand colors (Purple, Coral, Blue, Green)

### 5. Add Text Overlays (Optional)
You can add text overlays in Canva or Figma:
- Top or bottom of screenshot
- Large, bold text (28-36pt)
- White text with semi-transparent background
- Highlight key feature benefit

## After Capturing Screenshots

1. **Resize if needed:** Ensure all are exactly 1080 x 1920 pixels
2. **Optimize:** Compress to reduce file size (keep under 8 MB each)
3. **Name clearly:** `screenshot_01_chat.png`, `screenshot_02_conch.png`, etc.
4. **Save to folder:** Create a `play_store_assets/screenshots/` folder
