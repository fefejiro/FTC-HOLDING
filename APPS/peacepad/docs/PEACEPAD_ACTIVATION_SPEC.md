# PeacePad Activation Spec

Status: PROPOSED  
Last updated: 2026-07-23

## Activation definition

Activation is the first meaningful improvement a user experiences, not installation or account creation.

## Activation sequence

1. Choose a primary goal.
2. Create or import one parenting arrangement.
3. Prepare one calm communication.
4. Log one parenting event or child call.
5. Review the resulting timeline.

## Qualifying activation events

- calm_rewrite_accepted
- parenting_event_created
- child_call_scheduled
- child_call_completed
- child_call_missed
- evidence_uploaded
- evidence_categorized
- timeline_viewed after a created record

## Non-qualifying events

Install, account creation, screen view, notification permission, or passive return.
