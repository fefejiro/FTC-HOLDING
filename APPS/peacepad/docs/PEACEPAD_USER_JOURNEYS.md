# PeacePad User Journeys

Status: PROPOSED  
Last updated: 2026-07-23

## Guest first value

1. User opens PeacePad.
2. User chooses a primary goal.
3. User drafts or pastes a difficult message.
4. PeacePad suggests calmer wording.
5. User copies or edits the message.
6. Activation is counted only if the user completes the meaningful action.

## Parenting-time journey

1. User adds an arrangement or visit expectation.
2. User logs completed, missed, changed, public-only, or supervised contact.
3. User attaches a screenshot, note, or document if relevant.
4. PeacePad places the item on a timeline.
5. User reviews a weekly summary.

## Evidence journey

1. User uploads one record.
2. PeacePad preserves original metadata and hash.
3. User confirms date, source, people, and category.
4. AI extraction is optional and labelled.
5. User includes or excludes the item from an export.

## Professional handoff journey

1. User selects date range and categories.
2. PeacePad generates an index and chronological draft.
3. User reviews and redacts.
4. User exports a PDF/ZIP package.
5. Professional reviews outside PeacePad unless professional accounts are enabled.
