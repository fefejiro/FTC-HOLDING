# PeacePad Retention Model

Status: PROPOSED  
Last updated: 2026-07-23

## North Star metric

Weekly organized co-parenting actions completed per active family.

## Qualifying weekly actions

Calm rewrite, parenting-time event, child-call record, visit confirmation, evidence upload, evidence confirmation, weekly review, timeline export, co-parent interaction, or professional package review.

## Retention definitions

- Day 1: user returns or completes a second meaningful action within 24 hours.
- Week 1: user completes at least one meaningful co-parenting action in the following week.
- Month 1: user maintains an active timeline, schedule, evidence, or communication workflow across the month.

## Anti-metrics

Do not reward passive screen time, unnecessary message volume, conflict volume, evidence hoarding, or compulsive app use.
