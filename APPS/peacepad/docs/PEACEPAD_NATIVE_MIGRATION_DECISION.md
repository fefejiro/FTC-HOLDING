# PeacePad Native Migration Decision

Status: PROPOSED decision framework  
Last updated: 2026-07-23

## Current recommendation

Remain with the current React web + Capacitor architecture for the submitted release and near-term Premium validation. Revisit React Native only after the data model, evidence workflows, and retention evidence are stronger.

## Decision options

1. Remain with Capacitor.
2. Add selective native plugins.
3. Build a parallel React Native client.
4. Migrate later.
5. Reject migration.

## Approval gate

Migration cannot begin until App Store review is complete, v1 is tested end to end, and the founder approves a separate release plan.
