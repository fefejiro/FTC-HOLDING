# PeacePad Premium PRD

Status: PROPOSED  
Last updated: 2026-07-23

## Premium promise

Turn scattered parenting records into organized, source-linked timelines and summaries for user and professional review.

## Target users

- Parents with high-frequency co-parenting conflict.
- Self-represented parents organizing records.
- Parents managing missed contact, public/supervised visits, or structured weekly calls.
- Professionals who need clean client handoff packages.

## Premium modules

| Module | User value | First release posture |
| --- | --- | --- |
| Evidence Vault | Keep original records and metadata together | Build after storage/privacy design |
| Parenting Time Proof | Log visits, call attempts, and outcomes | Build as manual logs first |
| Court Prep Workspace | Produce timelines, indexes, and draft summaries | Draft only, professional review |
| Professional Collaboration | Share controlled packages with lawyers/mediators | Later, permission-heavy |

## Premium guardrails

- AI never replaces originals.
- Every generated summary links to source items.
- User confirmation is required before exports.
- No claim of legal sufficiency.
- No sensitive data in analytics.
- No real court records in test fixtures.

## MVP definition

A user can create a case binder, upload/tag evidence, log parenting-time/contact events, attach evidence to events, view a timeline, and export a draft lawyer-review package.
