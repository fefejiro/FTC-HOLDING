# PeacePad Next PRD

Status: PROPOSED  
Last updated: 2026-07-23

## Product thesis

PeacePad Next is a co-parenting communication, parenting-time, evidence-organization, and court-preparation workspace for separated families navigating conflict or difficult coordination.

It helps users document accurately, communicate calmly, follow arrangements, protect child stability, and prepare responsibly.

## Current architecture

VERIFIED: React web app + Express/Railway API + Capacitor iOS shell. The current submitted app must not be rewritten during App Review.

## Modules

### 1. Peaceful Communication

Calm rewrite, tone intervention, structured request builder, response suggestions, delayed-send reflection, child-centred language suggestions, and exportable communication history.

### 2. Parenting Time and Contact

Parenting calendar, public/supervised visits, pickup/drop-off records, child-call schedule, missed/completed/refused/rescheduled call logs, visit notes, reminders, and arrangement-compliance timeline.

### 3. Case Binder and Evidence Vault

Upload screenshots, PDFs, court orders, endorsements, disclosures, emails, photographs, receipts, school/medical records, call logs, visitation records, and professional notes. Preserve originals, hashes, timestamps, source, user description, extraction status, and export history.

### 4. Court Prep Workspace

Chronology builder, parenting-time report, missed-contact report, communication summary, expense schedule, disclosure checklist, document index, event timeline, lawyer handoff package, mediator package, affidavit outline, and export bundle.

## Non-goals

- Legal advice.
- Court filing automation.
- Guaranteed admissibility.
- Full React Native migration.
- Production billing.
- Public storage of private records.

## First implementation batch after approval

Onboarding carousel, goal selection, activation checklist, parenting-time event model, child-call event model, basic evidence-upload model, manual timeline, privacy-safe analytics, safe-area/keyboard fixes, and feature flags for unfinished Premium surfaces.
