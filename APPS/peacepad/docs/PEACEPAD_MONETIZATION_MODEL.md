# PeacePad Monetization Model

Status: PROPOSED  
Last updated: 2026-07-23

## Model

Subscription tiers are preferred over advertising. Do not implement billing until explicitly authorized.

| Tier | Target user | Core job |
| --- | --- | --- |
| Free | New or low-frequency user | Calm communication and basic organization |
| Plus | Active co-parent | Logs, schedules, reminders, longer history |
| Premium | High-conflict or court-prep user | Evidence Vault, timeline, exports |
| Professional | Lawyers, mediators, support workers | Controlled client workspaces and review |

## Guardrails

- No advertising as primary model.
- No payment-card data stored outside approved payment systems.
- Cancellation and refund policies must be plain.
- Free users should still receive meaningful calm-communication value.
