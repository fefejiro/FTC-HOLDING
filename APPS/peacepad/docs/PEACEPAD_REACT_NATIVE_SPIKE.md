# PeacePad React Native Spike

Status: PROPOSED research only  
Last updated: 2026-07-23

## Rule

React Native is a research lane only. It must not interfere with the submitted app, production web app, bundle ID, certificates, App Store review, or production database.

## Spike scope

Synthetic-data-only onboarding carousel, calm rewrite screen, parenting-event screen, one document-upload flow, and local navigation.

## Compare

Current Capacitor, React Native, Expo/EAS, native Swift, and hybrid shared-domain architecture.

## Decision factors

Code reuse, development time, migration risk, App Store risk, WebRTC, document upload, notifications, secure storage, offline operation, accessibility, analytics, testing, release process, staffing, and cost.
