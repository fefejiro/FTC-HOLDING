# PeacePad Ringtone

## Required File

Place your ringtone audio file here as `peacepad_ring.mp3`.

## Recommended Specifications
- **Format**: MP3
- **Duration**: 2-3 seconds (will loop)
- **Volume**: Normalized to -3dB
- **Sample Rate**: 44.1kHz or 48kHz
- **Bitrate**: 128kbps or higher

## How to Add

1. Create or obtain a ringtone audio file
2. Save it as `peacepad_ring.mp3` in this directory
3. The ringManager will automatically use it for incoming calls

## Temporary Workaround

Until a custom ringtone is added, the system will attempt to use `/sounds/peacepad_ring.mp3`. 
You can use any short, pleasant sound that's suitable for a phone call notification.

## Suggested Sources
- Create using a DAW (e.g., GarageBand, Audacity)
- Use a royalty-free sound library
- Record a custom tone

## Testing

After adding the file, test it by:
1. Clicking anywhere in the app to unlock audio
2. Making a test call between two devices
3. Verifying the ringtone plays on the receiver
