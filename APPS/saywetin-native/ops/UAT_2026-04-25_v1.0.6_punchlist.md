# SayWetin UAT — 2026-04-25 — v1.0.6 (vc25, prod)

Source: founder voice walkthrough on Pixel device, live prod build from Play install (or sideload from same AAB).

## P0 — Quick wins (bundle into Slice 3 ship)

| # | Area | Issue | Fix |
|---|------|-------|-----|
| 1 | App icon | Generic radar/Matrix circle, no brand. Phones show "SayWetin" with target icon — does not read as brand. | Replace adaptive icon foreground/background with SayWetin brand mark. Generate full mipmap set + monochrome. |
| 2 | Listen header | "SayWetin" title is too large + italicized; wraps awkwardly. | Single line, slightly smaller, drop italic, weight 600 max, tighter letter-spacing. Premium look. |
| 3 | Two CTAs | Mic button (with breathing animation) AND "Start Match" button below — confuses users. | Collapse to single primary CTA. Tap mic = start match. Remove the secondary button. |
| 4 | Listening duration | 12s feels long; should recognize as soon as fingerprint hits, not wait full window. | Early-stop on first ACRCloud match candidate. Cap at ~8s for first attempt; only extend if ambiguous. |
| 5 | Spotify link | "Spotify" link does nothing / does not open app or web. | Use `Linking.canOpenURL("spotify:track/<id>")` first, fall back to https URL. Verify URL is non-empty before rendering chip. |
| 6 | YouTube link | Same — does nothing. | Same fix pattern. |
| 7 | Genre chip | "Afrobeats" chip looks like a button; nothing happens on tap. Also "Now Playing" chip ambiguous. | Either wire genre tap to filter, OR strip the pressable affordance (no shadow/outline) so it reads as a label. |

## P1 — Medium (this slice if cheap, else Slice 4)

| # | Area | Issue | Fix |
|---|------|-------|-----|
| 8 | Live Lyrics gate | Found a song → "Follow Live Lyrics" button. User wants lyrics IMMEDIATELY in the artist card area, scrolling karaoke-style. | Auto-show inline lyrics in the result card area. Drop the explicit Follow CTA. Keep a small "Expand" if needed. |
| 9 | Lyrics layering | "Synced lyrics not yet ready, showing best available" + alternative meaning content stacked. Too many layers. | Single view. If synced lyrics ready → show. If not → show plain lyrics quietly with a tiny "auto-syncing…" inline spinner. No alt-meaning panel by default. |
| 10 | Rotating mic copy | "Tap to capture live audio you can sing, hum or play music" — fine, but should rotate to feel more alive/PR. | Pick from a 4–6 line copy bank on each session. |
