# Funding Positioning Memo Pack

This folder captures the current Canadian funding-positioning narrative for:

- `ATEAM`
- `Una Labs`
- `PeacePad`

These memos are meant to help with:

- grant and program framing
- partnership conversations
- commercialization narratives
- internal copy and positioning alignment

## Working Rule

These are positioning memos, not legal or tax advice.

Funding programs, windows, and eligibility rules can change. Re-verify the current status before applying.

## Verification Date

Verified against official sources on `2026-04-07`.

## Core Narrative

Across all three products, the preferred framing is:

- trusted workflow infrastructure
- governed AI enablement
- human approval before action
- decision-ready outputs
- measurable operational outcomes

Avoid defaulting to:

- chatbot language
- AI app language
- generic AI studio language
- claims about sovereignty or hosting guarantees that are not yet implemented

## Current Read

- `SR&ED` remains the most dependable baseline route for eligible Canadian R&D work.
- `NRC IRAP AI Assist` is the strongest active support lane for practical AI product development and validation by Canadian SMEs.
- `AI Compute Access Fund` is a readiness target, not an immediate cash source, because the most recent call is closed.
