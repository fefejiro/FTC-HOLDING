# ATEAM Funding Positioning Memo

## Positioning

ATEAM should be presented as a `trusted AI workflow infrastructure layer`.

It is strongest when described as a system that turns:

`rough request -> structured intake -> scoped plan -> human approval -> decision-ready output`

It should not be positioned as:

- a chatbot
- a generic AI app
- a Replit-like builder
- an AI studio gimmick

## Best Narrative

ATEAM is a Canadian AI workflow infrastructure platform that helps organizations turn rough requests into structured plans, governed execution paths, and decision-ready artifacts with visible accountability, auditability, and human approval.

That framing is stronger for:

- SR&ED
- NRC IRAP AI Assist
- enterprise buyers
- public-interest or public-sector adjacent reviews
- partnership conversations

## Best-Fit Funding Path

### 1. SR&ED

Use SR&ED to frame the technical uncertainty and experimentation inside ATEAM, including:

- request normalization quality
- planning and stage-state orchestration
- evaluation and rubric design
- artifact quality and drift reduction
- trust, approval, and audit architecture
- reliability and performance testing

### 2. NRC IRAP AI Assist

Use NRC IRAP AI Assist to support:

- AI-assisted product development
- workflow testing and validation
- experimentation around quality and usability
- tool and model selection
- practical commercialization work for Canadian SMEs

### 3. AI Compute Access Fund

Treat this as a readiness lane for the next intake rather than immediate funding.

ATEAM is a fit when it can show:

- a real product
- Canada-based R&D
- commercialization path
- measurable cloud compute usage
- evaluation and pilot workloads tied to product value

## Product Changes That Strengthen The Narrative

ATEAM should visibly emphasize:

- approval gates
- audit trail and logs
- scoped outputs
- constraints and non-goals
- traceability from request to artifact
- decision-ready packaging

The public surface should feel workflow-first, not cast-first.

## Claims Intentionally Avoided

Do not claim:

- sovereign infrastructure that is not yet implemented
- Canadian-hosted guarantees that are not yet verified
- durable shared cloud persistence while the current public demo is still using fallback mode

Safer language:

- built for governed AI workflows
- designed for organizations that need clearer execution and better accountability
- human approval before action

## Current Product Gap

ATEAM now has a stronger workflow-first public narrative, but the shared backend still needs to return for durable multi-user persistence and fully shared run history.
