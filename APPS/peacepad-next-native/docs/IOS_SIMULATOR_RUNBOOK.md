# PeacePad Next Native iOS Simulator Runbook

Last updated: 2026-07-23

## Why this exists

The FTC monorepo root has older React dependencies used by other apps. The PeacePad native lab correctly uses Expo SDK 54 with React `19.1.0` and React Native `0.81.5`, but Expo Doctor sees the monorepo root React `18.3.1` as a duplicate.

To avoid changing the whole portfolio just to test this lab, run the native prototype from a standalone simulator workdir generated by script.

## From the FTC monorepo

```powershell
cd "C:\FTC HOLDING"
npm --workspace=@ftc/peacepad-next-native run guardrails
npm --workspace=@ftc/peacepad-next-native run typecheck
npm --workspace=@ftc/peacepad-next-native run sim:prepare
```

The script creates:

```text
APPS/peacepad-next-native/.sim/peacepad-next-native-ios
```

That folder is ignored by Git.

## On MacInCloud

Copy or pull the repo, then run:

```bash
cd "/path/to/FTC HOLDING"
npm --workspace=@ftc/peacepad-next-native run sim:doctor
```

If doctor passes, run:

```bash
npm --workspace=@ftc/peacepad-next-native run sim:ios
```

This starts Expo from the standalone workdir and opens the iOS Simulator.

## If Simulator does not open

Open Xcode once and accept any prompts, then run:

```bash
xcrun simctl list devices available
open -a Simulator
npm --workspace=@ftc/peacepad-next-native run sim:ios
```

## Safety boundaries

- This is not the submitted App Store app.
- Bundle ID remains `ca.peacepad.nextnative.lab`.
- Production API writes remain disabled.
- No private court files or real evidence should be imported.
