## Premium ideas carried forward

- Case Binder / Evidence Vault.
- Parenting Time and Contact Proof.
- Peace Calls as schedule/attempt/outcome proof before recording.
- Legal Prep Assistant as source-linked drafts, not advice.
- Export packages as the premium "aha" moment.
- Private-by-default evidence posture.
- No real court documents in repo/test fixtures.

## Improvements in native lab

- Premium dashboard is value-first instead of module-first.
- Binder metrics show why Premium matters.
- Vault cards show status, tag, linked event, and integrity note.
- Logs separate call/contact proof from risky recording/transcription.
- Timeline has explicit source-link and legal-boundary copy.
- Export screen frames the product as a clean review package, not file dumping.
- Case Binder setup separates practical setup from sensitive details.
- Evidence detail tests the metadata/review step before AI summaries.
- Contact logs use neutral outcome labels instead of accusation-first labels.
- Export checklist makes user confirmation explicit before sharing.
