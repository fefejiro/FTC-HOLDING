# PeacePad Next Native Feature Test Plan

Last updated: 2026-07-23

## Test with mock data first

| Feature | Test question | Pass signal |
| --- | --- | --- |
| Onboarding | Can a user pick their goal quickly? | Goal selected in under 60 seconds |
| Calm Compose | Can the app create calmer wording without sending automatically? | User sees editable suggestion |
| Parenting-Time Log | Can user log visit/call outcome neutrally? | Timeline item created |
| Evidence Vault | Can user attach source metadata to an event? | Attachment metadata appears without private content leakage |
| Timeline | Can user understand what happened chronologically? | Items group by event type/date |
| Court Prep | Are summaries clearly labelled as drafts? | No legal-advice wording |

## Required device checks

- Small iPhone.
- Large iPhone.
- iPad.
- Dark mode.
- Large text/accessibility.
- Slow network.
- Offline mode.

## Not tested yet

- Real production auth.
- Real uploads.
- Real calls.
- Real App Store build.
