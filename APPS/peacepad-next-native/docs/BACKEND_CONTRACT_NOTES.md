# PeacePad Next Native Backend Contract Notes

Last updated: 2026-07-23

## Goal

Keep the future native client compatible with the current PeacePad backend domain model where possible.

## Candidate shared concepts

- User/session.
- Messages and tone preview.
- Parenting events.
- Scheduled child calls.
- Documents/attachments.
- Timeline items.
- Audit logs.
- Usage metrics.

## Contract rule

The native lab may define TypeScript mock contracts, but production API writes stay disabled until a separate backend compatibility review.
