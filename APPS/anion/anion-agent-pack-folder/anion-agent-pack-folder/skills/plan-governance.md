# Skill: plan governance

Use this skill when shaping or reviewing work.

## Checklist

- what milestone is this
- what dependency must land first
- who owns the task
- who reviews it
- what is the definition of done
- what status or ADR files must update

## Questions to answer

- is this in scope now
- does this require approval
- does this change the locked stack
- is the repo ready for this change

## Output shape

- short summary
- dependencies
- acceptance criteria
- likely files
- risks
