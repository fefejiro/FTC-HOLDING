# Compliance

## Product Classification

Bushy Bet is not a sportsbook.

## Restricted Activities

- No deposit handling
- No withdrawal handling
- No bet processing
- No auto-betting execution

## Affiliate Controls

- affiliate links must be verified before publication
- affiliate destinations should be licensed operators in supported jurisdictions

## Launch Controls

- jurisdiction checks are required before public launch
- local regulatory review must be completed for each target market
- messaging must avoid guaranteed-win claims
