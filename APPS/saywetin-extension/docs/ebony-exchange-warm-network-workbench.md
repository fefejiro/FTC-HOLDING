- Friend-of-friend activity where there is already mutual social context.

2. Leave 1-3 thoughtful comments where there is a real reason to contribute.
3. Prioritize comments that show personality, respect, humor, local familiarity, or shared scene interest.
4. Avoid commenting with immediate sexual asks, copy-paste compliments, or recruitment language.
5. Save promising profiles only after seeing local fit, activity, and compatibility signals.

Good comment styles:

- Welcome/support: friendly response to a new local post.
- Shared-context: mention a local munch, group topic, or common scene interest.
- Conversation starter: ask a respectful question that continues the thread.
- Appreciation: acknowledge a good boundary, thoughtful post, or useful event share.

Avoid:

- Commenting only on photos.
- Repeating the same line across posts.
- Asking for DMs before rapport exists.
- Using EbonyExchange language in women-only or no-unicorn-hunting spaces.
- Engaging where the group rules or post tone clearly reject men, couples, or outreach.

After 2-3 genuine interactions with the same person or group context, move the profile to manual review before any follow or message decision.
