# Contributing to SayWetin Extension

Thank you for your interest in contributing!

## How to Contribute
- Fork the repository and create your branch from `main`.
- For small, atomic tasks, use the [Agent-Ready] issue template.
- For improvements, use the [Continuous Improvement] template.
- Make sure your code passes lint and tests before submitting a PR.

## Code Style
- Use Prettier and ESLint (run `npm run lint` and `npm run format`).
- Keep changes focused and well-documented.

## Pull Requests
- Reference the issue number in your PR.
- Add clear descriptions and acceptance criteria.
- All contributions require review and approval.

## Questions?
