## Hour 2 — Deploy to Cloudflare Pages

Two Pages projects:

**`gidi-dashers` (the game)**
- Connect to git or use `wrangler pages deploy ./dist`
- Build command: `npm run build`
- Output dir: `dist`
- Env vars: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
- Custom domain: `play.unalabs.cloud` (or `gidi-dashers.pages.dev`)

**`gidi-dashers-portal` (landing + leaderboard)**
- Build command: `npm run build`
- Output dir: `out`
- Env vars: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_GAME_URL`
- Custom domain: `gididashers.unalabs.cloud` (or root `unalabs.cloud/gidi-dashers`)

## Hour 3–4 — Android (TWA via Bubblewrap)

Prereqs: JDK 17, Android SDK, Bubblewrap CLI (`npm i -g @bubblewrap/cli`).

```powershell
cd "C:\FTC HOLDING\APPS\gidi-dashers"
# initialise from the manifest we already wrote
bubblewrap init --manifest=https://gidi-dashers.pages.dev/manifest.webmanifest
# accept defaults; package id = com.ftcholding.gididashers
bubblewrap build
```

Outputs: `app-release-bundle.aab` (upload to Play Console) + `app-release-signed.apk` (test on device).

**Critical:** Cloudflare Pages must serve `/.well-known/assetlinks.json` for Digital Asset Links (Bubblewrap prints exact contents to publish). Drop the file in `gidi-dashers/public/.well-known/assetlinks.json` and rebuild.

## Hour 5–8 — Play Console internal track

Create app in Play Console:
- App name: **Gidi Dashers**
- Default language: en-US
- App / Game: Game
- Free / Paid: Free
- Declarations: ads (No), in-app purchases (No for v0.1)

Required listing assets (drop in `gidi-dashers/store-assets/` after generating):
- App icon: 512×512 PNG (`icons/icon-512.png`)
- Feature graphic: 1024×500 PNG
- Phone screenshots: 8× (1080×1920 PNG, captured from device or emulator)
- Short description (≤80 chars): "Run Gidi. Dodge danfo, molue, LASTMA. Stack naira."
- Full description (≤4000 chars): use `store-assets/description.md`
- Privacy policy URL: `https://gididashers.unalabs.cloud/privacy/` (page TBD — boilerplate ok for v1)
- Content rating: questionnaire (likely PEGI 3 / ESRB E)
- Data safety: device ID + score (no PII), no third-party sharing

Upload `.aab` → Internal testing track → add testers → Roll out.
