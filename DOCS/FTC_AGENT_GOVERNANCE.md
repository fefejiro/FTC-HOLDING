# FTC Agent Governance

Status: PROPOSED  
Last updated: 2026-07-23

## Global rules

Agents may inspect, document, test, and propose. Agents may not automatically deploy production, submit App Store builds, change billing, expose secrets, revoke certificates, accept legal agreements, merge automatically, modify private evidence, or create public issues containing sensitive information.

## Required gates

Human approval is required for production deployments, App Store submissions, billing, legal terms, data deletion, privacy-policy changes, and public sharing of sensitive content.

## Proof requirements

Every agent output must identify files touched, proof state, risks, stop conditions, and next owner action.
