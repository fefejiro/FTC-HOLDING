# Weekly Execution Cadence Quickstart

Last updated: 2026-03-19

## Weekly rule
Every week should have:
- one money move
- one product move
- one leverage move
- a clear follow-up rhythm

## Monday
- set the week
- choose the 3 core moves
- clean stale tasks

## Tuesday to Thursday
- execute
- move outreach forward
- move one product step forward
- update trackers after real actions

## Friday
- review results
- park what no longer matters
- choose what carries forward

## Daily rule
- morning = choose today’s moves
- midday = re-focus if drifting
- end of day = update next actions

## Reset if things feel messy
- trim active priorities
- re-run idea triage
- re-center on the money move first
