## Purpose

This document classifies current projects and surfaces by operating role so future decisions are faster and less emotional.

Use this before starting new work.

## Categories

### Push Now
Actively advance. Connected to revenue, strategic product progress, or immediate business clarity.

### Maintain
Keep healthy and accurate, but do not let it consume disproportionate attention.

### Internal Only
Useful for leverage and execution, but not a priority public narrative.

### Experiment
Allowed to exist, but should not consume core attention unless promoted intentionally.

### Avoid Sprawl
Things that should not multiply without clear strategic reason.

## Default Decision Rules

### If a project creates near-term cash
- classify as Push Now
- usually route through Una Labs

### If a project strengthens flagship product position
- classify as Push Now
- usually route through product-specific docs and roadmap

### If a project mostly helps internal execution
- classify as Internal Only
- do not force it into public marketing unless intentionally productized

### If a project is interesting but not urgent
- classify as Maintain or Experiment
- do not let it displace revenue work

## What to Resist

Resist:
- turning every useful tool into a new brand
- letting internal platforms compete with revenue surfaces for attention
- polishing experiments as if they are already businesses
- broad repo cleanup without operating value

## Operating Conclusion

Right now the company should behave like this:
- Una Labs = sells
- PeacePad = leads strategic product identity
- SayWetin = maintains product credibility
- ATEAM = increases internal leverage
- experiments stay contained until earned
