# Product Portfolio Brief - 2026-05-26

## One-Line Positioning

FTC Holding / Una Labs is a solo-founder product studio building practical AI-assisted software, client launch systems, and thin durable operating infrastructure.

## Stage Messaging

| Stage | Meaning | Public wording |
| --- | --- | --- |
| Live | Real public surface is available and can be shown. | "Live web app", "Live on Google Play", or "Public site live". |
| Demo-ready | Can be shown as a guided walkthrough, but should not be sold as fully self-serve. | "Demo-ready workflow", "operator-guided demo", "internal workflow surface". |
| Pre-launch | Product has repo/workflow substance but is not public-market ready. | "Pre-launch case study", "roadmap-backed product", "release candidate". |
| Post-launch hardening | Public surface exists, but operations or client rollout still need tightening. | "Public site live / post-launch hardening". |

## Product Cards

### Dispatch

Live web app for Ottawa roadside intake, operator routing, and incident watch. Public proof is the Dispatch web surface and Una Labs product page. Position it as live web software; keep mobile store status separate.

### PeacePad

Live communication-safety product focused on the pre-send moment. Position it as a product proof for AI-assisted communication and high-stakes message review.

### SayWetin

Play Store candidate for Nigerian music, slang, lyric meaning, and cultural context. Position it as a clean concept/product track until tested Android release is pushed.

### Anion Class App

Pre-launch classroom workflow for tutor discovery, parent/student onboarding, bookings, and live lessons. Use "Anion Class App" consistently. Do not call it a marketplace until tutor supply and public operations are proven.

### Garden Cleaners

Public client launch for a cleaning business site and quote path. Position it as public site live with post-launch hardening around booking, portal operations, and local SEO setup.

### ATEAM

Demo-ready internal workflow surface for intake, scoping, artifacts, and delivery governance. Position it as the operating system behind Una Labs delivery, not as a bloated standalone product.

## Naming Guardrails

- Use "Una Labs" publicly unless a legal/company context requires "FTC Holding".
- Use "SayWetin" with a capital W.
- Use "Anion Class App" on first mention.
- Use "Dispatch" for the product and "Dispatch Emergency Prompt" only for Google Play/privacy contexts where that app name is required.
- Do not call Garden Cleaners a demo if presenting it as a client launch.

## Travel Talking Points

- "I build and operate production software through Una Labs, with a focus on lean systems that are easy to maintain."
- "The portfolio is staged honestly: Dispatch and PeacePad are live, Garden Cleaners is a public client launch, SayWetin is a Play Store candidate, and Anion is pre-launch."
- "ATEAM is my delivery workflow: intake, scope, artifacts, and execution state, with Codex as the operator brain."
- "I keep infrastructure thin so solo-founder maintenance does not become the product."
