# FTC Product Operating System

Status: PROPOSED  
Last updated: 2026-07-23

## Seven stages

| Stage | Question | Exit evidence |
| --- | --- | --- |
| Problem | Who hurts and how often? | Interview/user proof |
| Promise | What improvement is offered? | Clear positioning |
| Proof | Did users get value? | Activation/retention evidence |
| Product | Is the flow reliable? | Tests + QA |
| Performance | Does it grow sustainably? | Acquisition/retention/conversion |
| Platform | Can it scale safely? | Security/privacy/reliability |
| Portfolio Decision | What should FTC do next? | Scale/hold/merge/license/retire |

## Cadence

Weekly: proof review and top risks.  
Biweekly: product demo and backlog grooming.  
Monthly: portfolio decision review.

## Stop conditions

Pause work when evidence is missing, production risk is high, privacy is unclear, costs exceed budget, or the work distracts from the highest-impact product.
