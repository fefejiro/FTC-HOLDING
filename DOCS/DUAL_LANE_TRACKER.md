# Dual-Lane Tracker

Last updated: 2026-03-19
Owner: FTC HOLDING / Una Labs

## Purpose

This tracker exists because current execution has two real lanes:

### Lane A
Client cash through Una Labs offers

### Lane B
Job stability through aligned role targeting

Both lanes matter.
The goal is to run both without letting them blur into one messy pile.

## Operating Rule

Both lanes can move in the same week.
They should not compete for the same exact task slot in your head.

Use this tracker to keep:
- pipeline visibility
- follow-up visibility
- next action clarity
- emotional separation between client work and job search

# Weekly Review

At least once a week, answer:

## Client lane
- Which niche is responding best?
- Which offer is easiest to explain?
- Where are deals stalling?
- What small asset would improve close rate?

## Job lane
- Which roles are the best fit?
- Are applications too broad or still aligned?
- Is the profile narrative matching the market?
- Where are conversations stalling?

---

# Guardrails

## Do not let client lane drift into unpaid custom work
If a prospect wants too much before commitment, re-scope or close the loop.

## Do not let job lane drift into generic desperation mode
If a role does not match the actual story, it is probably not worth the attention.

## Do not merge the lanes mentally
Client cash and job stability support each other, but they are not the same workflow.
Track them separately.
