# Founder Dashboard

Last updated: 2026-03-19
Owner: FTC HOLDING / Una Labs

## Purpose

This dashboard is the daily operating view.

It exists to reduce mental tabs.
It is not a brainstorming space.
It is not a long-term archive.
It is the shortest possible view of what matters now.

## Daily Rule

Start here before building anything new.

At all times, keep visible:
1. one money move
2. one product move
3. one leverage move
4. follow-ups due
5. blockers waiting on outside action

If a task does not fit a current lane, it waits.
