# FTC Product Review Cadence

Status: PROPOSED  
Last updated: 2026-07-23

## Weekly

- App/release status.
- Proof-state changes.
- Top three risks.
- User feedback.
- Next smallest implementation batch.

## Biweekly

- Demo only verified or prototype-labelled work.
- Review activation and retention.
- Re-score portfolio.
- Archive stale docs.

## Monthly

- Decide Scale, Continue Testing, Hold, Merge, License, or Retire for each product.
