# FTC Cross-Project Velocity Log

Track every meaningful task across all projects. Review every Sunday.
Honest time estimates only. No rounding down.

---

## How to Use

1. Log a row immediately after completing any task (even 10 minutes).
2. Be honest about time spent.
3. Every Sunday, review the week: what took longer than expected? What pattern emerges?
4. Update sprint targets in FTC_MASTER.md based on what you learn.
