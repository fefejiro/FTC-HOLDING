# Anion Class App

Anion is an FTC-owned premium classroom and tutoring platform asset.

This documentation tree mirrors a Confluence-style project space inside the repo so product, architecture, decisions, and operating status remain available to both humans and coding agents.

## Sections
- `product/` for product definition, scope, roadmap, and user journeys
- `architecture/` for system design, data model, deployment, and observability
- `adr/` for decisions that shape the long-term product
- `status/` for weekly summaries, release notes, and test evidence

## Operating Rule
- Long-form docs reduce into the weekly summary.
- Weekly summary reduces into the machine-readable status artifact at `APPS/anion/ops/status-summary.json`.
- The status artifact is the input for repo and dashboard tracking.
