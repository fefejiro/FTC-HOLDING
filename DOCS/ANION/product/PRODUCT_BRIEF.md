# Anion Product Brief

## Purpose
Anion Class App is a premium classroom and tutoring platform that gives tutors, students, and parents a clean way to manage lessons, bookings, subscriptions, and live learning sessions.

## Users
- Tutors who need discovery, scheduling, live lesson delivery, and billing support
- Students who need session booking, lesson access, and progress visibility
- Parents who need supervised access to student bookings, subscriptions, and session history
- Internal operators who need quality control, support visibility, and product telemetry

## Core Product Loops
- Tutor discovery to booking
- Booking to live lesson room
- Subscription purchase to recurring usage
- Parent oversight to retention and support

## Product Positioning
This is not a throwaway demo. It is a long-term FTC product asset and showcase surface that can evolve into a standalone product if traction appears.

## Immediate Scope
- Web foundation on Vite and React
- React Native mobile foundation
- Supabase-aligned data model
- Stripe-aligned subscription model
- Daily React-aligned live session shell
- Repo-native governance and dashboard tracking

## Deliberately Deferred
- Full lesson tooling implementation
- Detailed analytics instrumentation code
- Production webhook handling
- Native build automation beyond stubs
