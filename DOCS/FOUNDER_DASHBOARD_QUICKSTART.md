# Founder Dashboard Quickstart

Last updated: 2026-03-19

## Why this exists

This dashboard is meant to reduce mental load and make daily execution obvious.

Use it to answer:
- what makes money today?
- what gets one step closer to stability?
- what one product move matters?
- what one leverage move prevents future chaos?

## How to use it each morning

1. Open `DOCS/FOUNDER_DASHBOARD.md`
2. Set the day’s money move
3. Set the day’s job move
4. Confirm one product move
5. Confirm one leverage move
6. Check follow-ups due
7. Ignore everything not on the board

## Rules

- If more than 3 core moves are active, cut something
- If a task is not tied to revenue, product, or leverage, question it
- If an idea appears, do not add it here unless it deserves active status
- This dashboard is the operating layer, not the archive

## Suggested cadence

### Morning
- choose today’s moves
- update counts
- identify follow-ups

### Midday
- check whether the money move is actually moving
- re-focus if drift started

### End of day
- log what changed
- decide tomorrow’s money move
- carry forward only the next necessary tasks

## Relationship to future Priority C pieces

This dashboard is the top layer.
Below it, supporting systems include:
- idea triage matrix
- dual-lane tracker (clients + jobs)
- weekly execution cadence
- outreach and follow-up workflow

The dashboard should stay simple even if the supporting systems grow.
