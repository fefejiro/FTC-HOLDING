# FTC Agent Output Standard

Status: PROPOSED  
Last updated: 2026-07-23

## Required output

- Objective.
- Scope.
- Files inspected.
- Files changed.
- Proof labels.
- Findings.
- Risks.
- Decisions required.
- Next action.

## Forbidden output

- Claims of launch without public proof.
- Claims of validation without user evidence.
- Private legal facts.
- Secrets, tokens, passwords, certificates, or personal children’s information.
